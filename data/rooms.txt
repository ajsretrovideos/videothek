# Raum-Zuordnung der Regale
#
# Format:   Regalname | Raum | Wand
#
#   Raum  1 = Hauptraum, 2 = zweiter Raum hinter der Tür
#   Wand  back = Rückwand, left = linke Wand, right = rechte Wand
#
# Die REIHENFOLGE in dieser Datei bestimmt die Position innerhalb einer Wand
# (von links nach rechts). Die Wand selbst steht direkt in der Zeile.
#
# Die Wandspalte ist optional. Lässt du sie weg, verteilt das Script die Regale
# gleichmäßig auf die drei Wände - aber dann ist nicht vorhersehbar, welches
# Regal wo landet. Für eine bewusste Anordnung: Spalte ausfüllen.
#
# Umsortieren heißt: Zeilen verschieben. Danach npm run build.
